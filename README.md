# NIFTY 50 Direction Signals

TradingView Pine Script indicator for NIFTY 50 direction signals using completed 5-minute and 25-minute candles.

- [Open the website](https://amalpradhan24-ops.github.io/Nifty-50-Daily-Trading/)
- [View the Pine Script](nifty_5m_25m_signals.pine)

Apply the indicator to a 5-minute NIFTY chart. It marks a CALL bias when both timeframes align upward and a PUT bias when both align downward. It does not place trades or guarantee results; validate signals and manage risk independently.

For first-time publication, open the repository's **Settings → Pages** and select **GitHub Actions** as the build source. The workflow deploys automatically on pushes to `main`.
